# Brief
The goal of the final project is to create an accessible, interactive photo gallery. Building on concepts that have been learning in [Javascript](https://www.coursera.org/learn/javascript/home/welcome) course, create my own HTML file with images and alternative text and then add the code to call functions to react  to common events such page loads, mouse movement, and keyboard access. In addition to reusing the functions from the earlier homework you will want to write code to automatically add the `tabindex` attribute to your figures.
