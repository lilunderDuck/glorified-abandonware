# Brief
The goal of the final project is to give me "the chance to create something unique using HTML code". In general I need to write code that will pass validation and accessibility checkers. The code must include elements for a `doctype`, `<head>`, `<body>`, `<title>`, and `<main>`. In the `<main>` it needs to have (at a minimum) headings, images, and a list.

# Instructions
1. Create a fully formed page with a doctype, head element, and body element
   1. Use three semantic tags, including h1 and main.
   2. Include a list with at least three items
   3. Include at least three images
   4. Include at least one link to an external source
2. Validate the site [using [`w3validator`](https://validator.w3.org/)].
3. Host and share the site
4. Peer review 3 other sites
