# Brief
The goal of this assignment is to provide additional practice styling my website. The job is to modify some existing CSS rules and add new ones. To improve accessibility I will also add a "Skip to Main Content" capability to each page. Of course, validate it through the [Wave validator](https://wave.webaim.org/) to check for color contrast errors.
