# Brief
In this assignment you will create an **original site** and then demonstrate the skills I have learned in [Intro CSS](https://www.coursera.org/learn/introcss/home/welcome) to style the site. Some of the skills include showing the ability to:
1. Implement a traditional "Skip To Main Content" link that is only visible on focus.
2. Ensure that the site has an accessible, attractively styled navigation.
3. Effectively use the grid and flex property values.
4. Use the box model to style elements in an attractive manner.
5. Use validators to ensure that the site is *syntactically correct* and accessible.

# Instructions
1. Create your own **three pages of HTML code**. Every page must have at least one image and at least one of those pages must have at least five (5) images.
2. Validate your html using [`w3validator`](https://validator.w3.org/).
3. Use the `position` property and the `:focus` pseudo-class to style your "Skip to Main Content" link. It should only be visible when the link is in focus.
4. Style your navigation in an attractive fashion – use at least three CSS properties
5. Style all images using the box model. At a minimum use `border`, `padding`, and `border-radius`.
6. Apply the grid property to at least one parent element. Use at least two columns, but feel free to use more!
7. Apply the flex property to at least one parent element. The navigation bar is one place to use flex. You can also use it on images if you would like.
8. Update at least one element using the `:hover` pseudo-class. Make sure that the hover property does something interesting.
9. Implement the `:nth-child` selector [...].
10. Validate the code using https://wave.webaim.org/ or the wave browser extension.
11. Submit the link [to the page].
12. Complete peer reviews.
